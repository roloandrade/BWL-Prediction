# BWL-Prediction

This machine learning model estimates the likelihood of an individual achieving a ≥5% reduction in body weight after a 12-week intervention based on a 1500 kcal/day Mediterranean diet. The predictive algorithm leverages 15 features selected through feature importance analysis, representing the most informative variables from an initial set of clinical predictors. This work is part of an ongoing research initiative led by the University of Valladolid.
